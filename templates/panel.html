添加 Cloudflare Token

粘贴一个 Zone.DNS 编辑权限的 API Token，系统会自动探测它能管理哪些域名。

创建方法：Cloudflare 控制台 → My Profile → API Tokens → Create Token → 模板 Edit zone DNS → Zone Resources 选你要管的域名 → 创建。
Token 只存在本服务器，客户端永远接触不到。

各机器自动拉取证书

用本机主机的更新密钥做鉴权，定时拉取通配符证书，变化时自动替换并 reload。

# 把 CERT_KEY 换成本机主机的更新密钥 curl -4fsSL https://{{ endpoint }}/get-cert.sh | \ CERT_KEY=你的主机密钥 \ CERT_DIR=/etc/ssl/mycerts \ RELOAD_CMD='nginx -s reload' bash
# 每12小时拉一次（证书60天有效，续期后自动同步） docker run -d --name cert-sync --restart=always \ -v /etc/ssl/mycerts:/certs \ -e CERT_KEY=你的主机密钥 \ -e CERT_API=https://{{ endpoint }} \ -e CERT_DIR=/certs \ curlimages/curl sh -c \ 'while true; do curl -4fsSL $CERT_API/get-cert.sh | sh; sleep 43200; done'
# crontab -e，每天5点检查 0 5 * * * CERT_KEY=你的主机密钥 CERT_DIR=/etc/ssl/mycerts \ RELOAD_CMD='systemctl reload nginx' \ bash -c 'curl -4fsSL https://{{ endpoint }}/get-cert.sh | bash'

落地文件：fullchain.pem + key.pem。私钥 600 权限。密钥可在各主机「接入」里查看。

客户端接入 ·

兼容 dyndns2：主机名做用户名、密钥做密码，任何标准客户端都能直连。

几乎所有软路由/NAS 内置 dyndns2，填这几项即可，无需装插件。
